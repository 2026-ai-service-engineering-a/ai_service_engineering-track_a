## 학습 목표

- AI 서비스가 기획 → 데이터 → 모델/LLM → API → UI → 배포로 이어지는 전주기를 설명할 수 있다
- 오픈소스 AI 생태계의 주요 구성 요소([[llm|LLM]], [[embedding|임베딩]] 모델, [[vector-db|벡터 DB]], 프레임워크)를 구분할 수 있다
- 다섯 개 프로젝트 트랙(및 자유 주제)의 차이를 이해하고 관심 방향을 1\~2개 고른다
- 개인 repo를 개설하고 앞으로의 산출물이 쌓일 구조를 잡는다

## 세션 실습 포커스

1. **과정 조망** — AI 서비스 전주기(5레이어)와 14주 로드맵
2. **엔지니어링 사다리** — 프롬프트 → 컨텍스트 → 하네스, 이 과정이 오르는 단계
3. **라이브 빌드** — 분식집 주문 에이전트를 지시 → 생성 → 검증 → 수정
   사이클로 완성하는 멘토 시연 (위 시연 저장소 참고)
4. **프로젝트 트랙 소개** — 다섯 트랙 + 자유 주제, 공통 역량(1\~9주차)과 개인 프로젝트(10\~14주차)
5. **개인 repo 개설** — 저장소 생성, README에 학습 목표 3줄 (세션 중 유일한 직접 실습)
