## 학습 목표

- AI 서비스가 기획 → 데이터 → 모델/LLM → API → UI → 배포로 이어지는 전주기를 설명할 수 있다
- 오픈소스 AI 생태계의 주요 구성 요소([[llm|LLM]], [[embedding|임베딩]] 모델, [[vector-db|벡터 DB]], 프레임워크)를 구분할 수 있다
- 다섯 개 프로젝트 트랙(및 자유 주제)의 차이를 이해하고 관심 방향을 1\~2개 고른다

## 다루는 내용

1. **AI 직무 지형** — 서비스 관점에서 본 역할 구분
2. **오픈소스 AI 생태계** — 모델, 프레임워크, 인프라 구성요소
3. **과정 구조와 트랙 소개** — 공통 기반(1\~9회차)과 개인 프로젝트(10\~14회차)
