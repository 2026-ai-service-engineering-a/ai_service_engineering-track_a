> **VOD 사전 시청** — 캡스톤 데모 (전체 그림)

## 학습 목표

- AI 서비스가 기획 → 데이터 → 모델/LLM → API → UI → 배포로 이어지는 전주기를 설명할 수 있다
- 오픈소스 AI 생태계의 주요 구성 요소([[llm|LLM]], [[embedding|임베딩]] 모델, [[vector-db|벡터 DB]], 프레임워크)를 구분할 수 있다
- 다섯 개 프로젝트 트랙(및 자유 주제)의 차이를 이해하고 관심 방향을 1\~2개 고른다
- 개인 repo를 개설하고 앞으로의 산출물이 쌓일 구조를 잡는다

## 세션 실습 포커스

1. **과정 조망** — AI 서비스 전주기와 14주 로드맵
2. **엔지니어링 사다리** — 스크립트에서 서비스까지, 이 과정이 오르는 단계
3. **프로젝트 트랙 소개** — 다섯 트랙 + 자유 주제, 공통 역량(1\~9주차)과 개인 프로젝트(10\~14주차)
4. **개인 repo 개설** — 저장소 생성, 기본 구조, 첫 커밋

## 산출물

- 개인 학습 목표 작성 (다음 주차 시작 전까지)
- 개인 repo (생성 + 기본 구조)
