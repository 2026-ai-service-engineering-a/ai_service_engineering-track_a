## 개요

Orca는 개발 중인 웹 앱에 [[agent|에이전트]] 개발 위젯을 심어, 브라우저에서
바로 Claude Code 세션을 띄우는 Laravel 도구입니다. 지금 보고 있는 페이지의
URL·라우트·화면(스크린샷)을 컨텍스트로 함께 넘겨, "보고 있는 것"을 그대로
지시에 담을 수 있습니다.

## 특징

- 페이지 컨텍스트(URL·라우트·인증 사용자) 자동 캡처
- 화면 요소 하이라이트·스크린샷 첨부
- 계획 후 실행(plan-before-execute) 흐름과 실시간 스트리밍 출력
- 로컬에서 동작 — 클라우드 중개 없음
