## 사용 도구 \{#tools}

강의·실습·개인 프로젝트에서 실제로 쓰는 도구와, 버전·스택을 확인하는 참고
사이트를 모았습니다. 각 항목을 누르면 상세 페이지로 이동합니다.

### 개발 도구 \{#dev-tools}

- **[Visual Studio Code](/stack/vscode/)** — 확장 생태계가 풍부한 무료 코드 에디터, 이 과정의 기본 에디터
- **[Docker](/stack/docker/)** — 애플리케이션을 실행 환경째 컨테이너로 묶어 재현하는 도구
- **[Orca](/stack/orca/)** — 웹 앱에 Claude Code 세션을 임베드하는 Laravel 위젯

### 참고 사이트 \{#reference-sites}

- **[endoflife.date](/stack/endoflife-date/)** — 소프트웨어·언어·프레임워크의 지원 종료(EOL) 일정 정리
- **[awesome-ai-stack](/stack/awesome-ai-stack/)** — AI 시스템 구축에 쓰는 도구·개념·실행 샘플 카탈로그

카테고리별로 묶어 보려면 [카테고리로 보기](/categories/tools/)를 눌러 주세요.
